# Microsoft 365 Setup – 1.0.0-alpha

Nach jedem Schema-Update einmal **Phase-1-Struktur prüfen / anlegen** ausführen. Die Provisionierung ist additiv: bestehende Listen und Felder bleiben erhalten, fehlende werden ergänzt.

Für den 1.0.0-alpha-Gesamtstand werden insbesondere Fahrzeug-Identifikations-/Maßfelder, erweiterte Komponentenfelder, Mautklassen und Testdatenkennzeichen ergänzt.
